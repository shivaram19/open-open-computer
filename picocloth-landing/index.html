What is PicoCloth, in plain English?

Imagine you could clone yourself 10 times. Each clone specializes in something different — one loves research, one writes code, one checks for mistakes, one organizes knowledge.

Now imagine they all share one brain. When one learns something, they all know it. When one makes a decision, the others remember why. Nothing gets lost.

That's PicoCloth. A fleet of AI agents that work together, share memory, and keep snapshots of everything they learn — so they never forget.

Meet your team

Each agent has a personality, a job, and a specialty. You talk to them via Telegram or a simple command line.

🧠

Node A — The Researcher

Asks deep questions, finds patterns, reads papers. Your curiosity engine.

⚡

Node B — The Builder

Writes code, deploys tools, ships features. Your execution machine.

🛡️

Node D — The Guard

Checks facts, spots contradictions, keeps things honest.

📚

Node H — The Librarian

Builds knowledge graphs, connects ideas, organizes everything.

🌐

Node I — The Router

Decides who does what. The project manager of the fleet.

📊

Node J — The Analyst

Tracks metrics, costs, and progress. Keeps you informed.

How it works (the simple version)

1

You ask a question

Via Telegram, CLI, or chat. "Find me research on AI memory systems."

2

The Router assigns it

Node I decides the Researcher (Node A) is best for this. It forwards the task.

3

The agent thinks and learns

Node A digs in, finds papers, extracts facts. Everything it learns is saved to shared memory.

4

Everyone benefits

Next time the Builder (Node B) codes something, it already knows what the Researcher found. No silos.

What can you do with it?

🔬 Deep Research Agents read, summarize, and cross-reference papers across days without losing context.
💻 Build Projects One agent designs, another codes, a third reviews. Like a tiny dev team.
📝 Content Creation Research facts, draft posts, check tone, publish — all coordinated.

🗂️ Knowledge Management Dump documents in. Agents extract facts, build graphs, connect dots.
🤖 Custom Workflows Train your fleet for your specific job. They adapt and improve over time.

Get started in 3 steps

You need a computer, an OpenAI API key, and about 10 minutes. That's it.

# 1. Set your API key export OPENAI_API_KEY="sk-your-key-here" # 2. Set up the shared memory ./scripts/init-shared-memory.sh # 3. Launch your fleet ./scripts/launch-fleet.sh start # 4. Chat with your team picocloth chat interactive

💡 Don't have an API key? The agents work with any OpenAI-compatible endpoint — including local models. See the full setup guide.

Why is this open source?

We believe agent swarms should be a public good. Not locked behind a corporate API. Not selling your data. Not training on your conversations.

Your fleet runs on your machine. Your memory lives in your files. Your agents work for you. If you unplug the internet, they keep working.
