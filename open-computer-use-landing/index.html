What is this, in plain English?

Imagine you could tell your computer what to do, and it actually understood you. Not with code. Not with menus. Just normal sentences.

That's Open Computer Use. It's a free, open-source tool that watches your screen, understands what you want, and clicks, types, and moves things for you — all through a simple chat interface in your browser.

It runs entirely on your own machine. Your data never leaves your house.

How does it work? (The simple version)

1

You type what you want

In a chat window in your browser. Like texting a friend.

2

The AI looks at your screen

It sees what's on your Windows desktop — buttons, text, icons — and figures out what to do.

3

It clicks, types, and moves for you

You watch it work in real-time. You can pause or correct it anytime.

Get started in 10 minutes

You need a Windows PC, Docker, and an AI API key (Google, OpenAI, or Anthropic). That's it.

# 1. Download the project git clone https://github.com/Clad3815/open-computer-use cd open-computer-use # 2. Put your Windows 11 ISO in the right folder # (Download from Microsoft, rename to custom.iso) # 3. Add your API key echo "GOOGLE_API_KEY=your-key" > server/.env # 4. Start everything npm install && npm run build docker-compose up -d cd server && npm start # 5. Open your browser # Go to http://localhost:2977 and start chatting

💡 New to this? The full step-by-step guide on GitHub walks you through every click.

Why run it on my own computer?

Unlike cloud AI assistants, your screen never leaves your machine. No company sees your files. No subscription fees. No "we've updated our privacy policy."

It's your computer, your data, your assistant. If you unplug the internet, it still works (with local models).
